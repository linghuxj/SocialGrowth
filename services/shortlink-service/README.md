# @socialgrowth/shortlink-service

SocialGrowth 导流短链与来源观察服务（交付模块 4）。本文描述当前业务要求，不证明服务已经完成实现或真实接入；产品发展见[能力路线](../../docs/product-roadmap.md)。

## 服务定位

- 关联客户、账号、内容及其可观察来源，记录原始访问、过滤后点击与跳转处理结果；三者不等于真实独立人数、页面到达或订单。
- 受众引导与真实可点击入口、片名、语言和客户目的地保持一致；客户只提供首页时如实说明查找路径，不承诺剧集精确直达。
- 链接预览与真实目的地内容一致，访问识别存在误差；不能以向平台隐藏落地内容或“零跳出”为功能目标。
- FB 按具体展示面和入口核验归因；YT Shorts 通过可用频道入口引导，共用链接至频道层级，不分摊为单条内容；IG 接入条件后续专项核查。
- 目的地变更记录授权、生效时间、历史版本及全部受影响入口；共用主页链接会同时影响旧内容，不自动转给新客户。正常退出按 G-02b 的继续/停用约定处理。
- 服务故障、目的地故障与平台拦截分别处置；平台在点击前拦截旧网址时，更换服务端目的地或域名不能保证救回历史入口。可修改的逐项处理，无法修改的记录影响并暂停相关新导流，不能自动绕过平台限制。

业务依据：[模块 4 与导流故障边界](../../docs/delivery-specification.md)、[受众路径与退出](../../docs/handoff/2026-09-19-business-flow-proposal.md)。

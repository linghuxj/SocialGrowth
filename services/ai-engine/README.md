# @socialgrowth/ai-engine

SocialGrowth 核心 AI 策略生成与规则推理中枢。

---

## 一、 服务定位

作为独立的服务层（Service），将 LLM 模型调用与业务逻辑解耦，独立承载前 3 个月系统的四大核心智能处理职责：
1. **Tag-to-Profile 智能匹配**：漫剧切片多维特征打标与矩阵账号画像的 Match Score 计算；
2. **AI 运营策略拟定**：结合经验规则、平台约束与受众定位，自动化生成发布文案与导流计划；
3. **经验规则引擎**：自然语言经验的结构化解析、三级规则冲突检测（官方规则/内部规则/假设）与版本管理；
4. **A/B 效果评估**：观察期数据指标对比，判定策略达标全量晋级或一键安全回退（Rollback）。

---

## 二、 目录结构

```
services/ai-engine/
├── prompts/              # 系统级提示词模板 (策略生成、规则解析、标签提取)
├── src/
│   ├── types.ts          # 数据契约定义
│   ├── matching-engine.ts# 切片与账号匹配算法
│   ├── rule-parser.ts    # 经验规则结构化与冲突检查
│   └── index.ts          # 统一服务导出
└── package.json
```

---

## 三、 成本核算与独立优势

- **预算隔离**：本服务所有对外 API 调用（如通义千问、DeepSeek、Claude 等）均由月度 2–5 万元的“产品 AI 调用”专项额度核销；
- **免除 UI 耦合**：Web 控制台通过 REST/gRPC 调用本服务，保证核心策略逻辑的高内聚与可测试性。

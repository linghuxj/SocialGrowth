# @socialgrowth/web-console

SocialGrowth 统一现代 Web 运营管理控制台（Human-in-the-loop 人机协同界面）。

**当前证据边界**：应用读取本地演示 JSON；现有按钮与提示不证明真实数据库、真机执行或供应商接入。B-05 对应的[关键表单与交互规格](../../docs/engineering/console-form-spec.md)已补齐，B-01 对应[目标持久化模型](../../docs/engineering/data-model.md)已修订；当前页面/类型/数据仍需在实现任务按本版对齐，不能把文档更新作为应用验收。

---

## 一、 系统定位与架构

作为 SocialGrowth 系统的统一前端应用，为单人专职运营人员提供直观、高效的监控与操作控制台，承接 7 大交付模块的前端可视化与人机交互流：

```
                              ┌───────────────────────────┐
                              │     apps/web-console      │
                              │ (Next.js / React 19 / UI) │
                              └─────────────┬─────────────┘
                                            │
                    ┌───────────────────────┼───────────────────────┐
                    ▼                       ▼                       ▼
          services/ai-engine      apps/artemis-controller   services/shortlink-service
          (策略/规则/匹配/评估)      (真机群控/状态/回执)       (短链统计/跳转流)
```

---

## 二、 7 大核心交付模块界面映射

1. **账号矩阵与设备映射看板（模块 1）**：
   - 物理真机池与账号专属绑定关系（1机1平台1号）；
   - 账号生命周期状态（冷启动、持续运营、受限警告、已置换）。
2. **切片资产库与独占排他监控（模块 2）**：
   - 漫剧切片视频资产管理与特征标签展示；
   - 展示内容身份、独占归属、审批与发布结果。既有四态示例不足以表达取消释放和未知结果；按 G-03 系列分别呈现，不把等待、设备恢复或删帖当作可再次发布。
3. **AI 策略工作台与规则引擎（模块 3）**：
   - 按受众时区生成排期草案，展示运营日、实际执行时间及内部批准频次；这些规则不是平台保证的安全上限。修改关键内容或排期后复核有效批准；
   - 批量通过、微调文案与驳回重生成；
   - 策略级“自主托管开关”：按 G-04 在已验证规则及明确授权范围内自动下发；新策略小批试验须先人工批准，展示假设、版本、账号/发布量、成本、期限及停止条件，启动批准不等于验证通过或自动扩大许可；
   - G-04a：非值守执行有效批准内发布，异常显示受影响/关联暂停范围、待核对结果、责任人与处理记录；人工核对后恢复，过期任务重排，不自动补发或因设备恢复解除业务暂停；
   - 经验规则库管理：自然语言录入、三级分类管理与规则冲突预警。
4. **导流短链分析与域名管理（模块 4）**：
   - 批量短链创建与目的地配置；
   - 区分服务故障、目的地失效与平台拦截，展示受影响旧链接和经授权的替代安排；
   - 预览与实际目的地一致，标记机器访问及识别不确定性，不保证零跳失；
   - 分开显示原始访问、有效点击、跳转响应和可核验的落地页到达；按实际入口解释归因，未接入的转化不推定为零或成功。
5. **账号异常与恢复中心（模块 5）**：
   - 区分登录挑战、临时功能限制、内容争议、推荐/变现资格、账号终止、流量待分析与设备执行故障，展示通知来源及证据；
   - 支持暂停、申诉/核查、权限确认、恢复或退出；备用资源须另核授权及平台许可，不默认用换号解除封禁。身份验证与恢复批准分开；应用清理不证明安全或可运营。
6. **Artemis 设备群控看板（模块 6）**：
   - 物理真机设备池在线状态、电池健康、网络延迟与当前执行任务；
   - 任务截屏流、动作自愈日志（Self-healing Logs）实时回显。
7. **数据归因与 A/B 策略实验大屏（模块 7）**：
   - 社媒官方 API 与第三方数据服务双轨采集指标聚合看板；
   - G-05：按主目标展示基线/候选比较、来源变化、缺失与不确定性；闭环验收、策略结论、业务目标及推广授权分别显示。无改善/证据不足不选赢家，必要执行或数据未完成不能标通过；推广需明确授权，回退不撤销历史结果。

## 三、 技术栈选型

- **核心框架**：React 19 + vinext / Next.js
- **组件库**：shadcn UI + Base UI (@base-ui/react) + Tailwind CSS v4
- **图表引擎**：Recharts (折线图、条形图、面积图)
- **图标系统**：Lucide React
- **编译工具链**：Vite 8 + oxlint + oxfmt

## 四、 环境变量配置 (`.env.local`)

开发时在当前目录创建 `.env.local` 文件：

```env
# 核心后端服务接口地址
VITE_AI_ENGINE_URL=http://localhost:3001
VITE_ARTEMIS_CONTROLLER_URL=http://localhost:3002
VITE_SHORTLINK_SERVICE_URL=http://localhost:3003

# 鉴权与租户标识
VITE_CONSOLE_AUTH_SECRET=your-console-auth-secret
```

## 五、 本地开发与构建指令

> [!NOTE]
> 遵循项目规范，本地环境由开发者手动启动与调试服务，禁止脚本自动后台驻留。

```bash
# 安装依赖
npm install

# 本地启动开发服务器
npm run dev

# 静态类型检查与代码规范检查
npm run lint

# 代码格式化
npm run format

# 生产环境编译构建
npm run build
```

## 2026-09-29 开发准入与交付顺序（历史）

截至 2026-09-29，业务基线至 R-156，主要架构按 ADR-0001～0011 确认，首批流程及最小契约已具备开发输入条件。当时判断为可以进入系统整体开发，按批次实现并验收；无需再开展全面需求访谈或等待全部设备能力预先验证通过。当时正式产品工程尚未搭建；当时已完成文档校准，并按用户要求形成[开发分工与质量执行手册](engineering/delivery/README.md)，作为后续任务分配、实施、评审及验收入口。

当时提出以下实施顺序，仅作历史规划参考；互不依赖的工作可并行，不减少首期完整范围：

1. 正式工程与首批身份归属闭环：运营登录及最小账号管理、多人限次限期邀请、提供者注册／登录、逐台关联、两端状态可见。
2. 接入及控制：设备认证、受限核验与 Tailscale 准入、首次配对、端点上报与重连、运营分配及初始化、暂停／恢复／退出。
3. 项目素材与媒体执行：项目及批准范围、人工素材、AI 安排、受控执行与平台核验；不依赖真机的项目和素材工作可提前实施。
4. 真实反馈与基础分佣：反馈进入后续有效安排，基础分佣记录及本人视图按已有规则实现；真实计佣前落实比例、到账及归属依据。
5. 首期全范围验收：覆盖全部平台形式、两类业务、异常恢复、交接和 20–50 台管理目标。

具体组件、版本、数据表、接口及会话机制在对应模块编码时落实；真实短信、安装分发和设备／网络资源在对应真实联调前落实；接入、停止及恢复证据在对应模块交付前补齐。Web 业务验收使用 Playwright 从真实页面操作，Android 原生及真机执行另留实际证据；开发准入不等于上线或首期验收通过。

首批数据至少区分运营、邀请及注册来源／名额消费关系、提供者、登录验证与管理会话、执行设备、本机安装身份、关联会话、设备归属及操作结果。手机号、网络 IP、队列消息和临时关联码不代替稳定业务标识；本机身份不获得完整管理登录权限。首批流程、最小数据及事务契约见[首批闭环](first-delivery-flow.md)；字段和认证参数随实现细化，不再逐项要求业务选型。

## Android 首期交付清单

正常路径为：受邀登录管理 → 逐台扫码关联 → 执行手机授权与条件检查 → 运营首次分配 → 初始化及发布身份核验 → 可接任务。运行期间走“发现本人协助 → 暂停并确认停止和控制交还 → 现场处理 → 主动请求恢复 → 系统复核”；永久退出另行处理，基础分佣独立查看。

| 交付项与顺序 | 最小交付内容 | 完成判据 | 依赖 |
| --- | --- | --- | --- |
| 1. 身份与关联 | 受邀注册、原号码登录、管理扫码确认、本机关联码；我的仅保留本人身份及必要帮助 | 同一提供者回到原记录；每台目标手机唯一关联；登录不接入管理手机；重复提交不重复建人或设备；管理与本机身份不能越权 | 邀请及短信通路、关联入口与身份校验方案 |
| 2. 接入与就绪 | 执行手机共用准备／检查／等待运营视图，管理端可看进展；对接运营分配与初始化结果 | Wi-Fi、管理连接、中心调试和业务网络分别有证据；分配、实际发布身份及初始化核验齐备才可接任务；单项通过不冒充全就绪 | 第 1 项；支持真机、官方 Tailscale 配套、首次中心配对与运营端衔接 |
| 3. 状态与暂停 | 管理首页、设备详情、仅本机状态；两端汇入同一设备暂停事实，必要协助从设备进入 | 明确本人下一步；请求记录、中心受理及实际停止可区分；单台暂停不误伤其他手机；离线和旧回执不虚报停止或清除暂停 | 第 1 项；执行通道停止与状态回传能力。与第 2 项同步验证，不等完整页面做完才测 |
| 4. 现场协助与恢复 | 复用同一设备协助页和进展区，明确处理结果与请求恢复两个动作 | 确认停止及控制交还后才提示现场处理；保存说明不恢复；明确请求后在有效授权内复核，通过且无其他阻断才继续有效任务；未知发布不重发 | 第 2、3 项；同机互斥、恢复检查及未决结果处理 |
| 5. 永久退出 | 目标设备确认页、同一详情内退出进展、运营交接及清理衔接 | 无需运营先批准即可停派；停止与登录清理分别确认；未决结果和历史保留；普通恢复和重连不能重新启用 | 第 3 项；运营交接与清理流程，不以清理能力代替停止能力 |
| 6. 基础分佣 | 本人列表与依据详情，沿用已确认的承接期间、到账与比例口径 | 预估收入、可结算佣金与实际已付分开；缺失显示待核对；不重复计佣、不暴露其他提供者资料、不把生成记录当付款 | 第 1 项身份隔离及真实收益依据；与控制链路并行，不作为媒体闭环前置 |

第 1～5 项共同支撑核心接入与控制闭环，不能以页面完成代替设备停止和恢复能力。起步可用一位提供者、一台执行手机验证，随后必须覆盖一人多机及另一提供者的身份隔离；这只是实施顺序，不缩减已确认的首期范围与 20–50 台管理目标。现有远程执行证据按 R-109 复用，新增路径单独补证。

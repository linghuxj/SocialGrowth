## 范围与排除项

- 运营创建、查询、复制和撤销可多人使用的邀请；成功注册次数上限和有效期可配置，同一共享码与链接共用额度；创建运营、实际注册提供者及关联进展可追溯。
- 只有最终注册成功才消耗一次名额。打开、复制、短信失败、验证码失败、重复提交、已有身份登录及新增设备均不扣次；到期、撤销或耗尽只阻止新注册，不取消已有身份或设备。
- WP-03 不实现短信发送/验证码供应商、提供者登录或实际注册页面；这些属于 WP-04。也不实现自动群发、逐人审批、预绑定手机号、虚构项目或独立工单系统。

## 第一阶段非作者复核整改

- 固定提交 `c120950` 复核结论为需修复：读取契约允许用量、状态及时间互相矛盾；创建响应的共享码与注册链接可能指向不同邀请；注册进展未说明完整或分页语义。
- 邀请快照新增服务端 `evaluatedAt`，由服务端权威时间按 revoked → expired → exhausted → active 顺序确定状态；TS 与 Python 运行时同时拒绝超额用量、错误状态、创建/到期/撤销/评估时间倒置。
- `registrations` 明确定义为完整成功注册集合，数量必须等于 `consumedUses`、提供者必须唯一、注册时间必须处于创建至评估窗口；剩余名额只由上限减已用量派生，不再增加可能矛盾的独立事实。
- 创建响应只携带唯一 43 字符 base64url 共享码；Web 后续从该值单向派生注册链接，结构上消除码与链接参数漂移。新增 TS/Python 反例回归后 contracts TS 13/13、Python 7/7 通过；仍须交同一窗口复核。
- 二次复核确认三项主问题方向正确，但发现撤销 response 未复用完整语义、JavaScript 毫秒与 Python 微秒精度不同、撤销时间可晚于评估时间。最终整改提取所有 TS 入口共用的语义函数，撤销 response 继续限定 revoked 且执行全部校验；TS/Python 都用“整秒＋任意小数位”精确比较，并要求 `createdAt <= revokedAt <= evaluatedAt`。新增亚毫秒及撤销 response 反例后 TS 15/15、Python 7/7 通过，仍待同一窗口复核。
- 三次复核确认上述三项关闭，仅发现 Zod 格式失败后继续执行语义校验时，畸形时间会抛普通异常。收口后精确比较对未通过结构校验的时间安全退出，由原 timestamp schema 返回标准失败；view、create、list、revoke 四个入口均增加 `safeParse` 不抛异常的反例。

## 第二阶段开发产物（待复核）

- 新增受运营者会话保护的邀请创建、列表和撤销服务及 `/api/operator/invitations` HTTP 边界；写操作强制校验同一 Host-only 会话的 CSRF token，所有响应禁止缓存并沿用统一产品错误 envelope。

## 第二阶段非作者复核整改

- 固定提交 `a8820e6` 复核结论为需修复：列表两段读取可能混合不同提交快照；注册等待邀请锁后仍以事务开始时间判断到期；pepper 轮换后的创建重放可能派生无效新码；竞争测试未确定性覆盖双方锁顺序和失败原因。
- 列表事务改用 PostgreSQL `REPEATABLE READ`，邀请事实、完整注册集合及有效设备数来自同一快照；真实数据库测试在邀请查询与进展查询之间提交注册，断言本次读取保持旧快照、下一次读取完整新快照。
- 注册获得邀请行锁后用 `clock_timestamp()` 重新判断邀请和手机验证是否仍有效，并以该锁后时间写入注册事实；撤销等待邀请行锁后同样重新取墙钟，避免撤销时间/评估时间早于已观察事实。
- 创建幂等重放用当前 key 派生 code 后必须与数据库原摘要常量时间匹配；轮换不匹配显式返回 `IDEMPOTENCY_RESULT_EXPIRED`。文档明确原 code 仍可使用，但若需保留恢复窗口必须保留旧 key，不能静默返回无效凭证。
- PostgreSQL 检查扩展到 18 项：用真实行锁屏障分别固定“撤销先行”和“注册先行”，断言另一方只能得到 `INVITATION_REVOKED` 或 `FACT_VERSION_STALE`；另覆盖等待跨过到期点、列表一致快照、key 轮换拒绝和非零设备进展。整改仍待同一复核窗口确认。
- 二次复核确认上述四项关闭，但发现列表虽已使用一致快照，仍可能用早于首次快照的事务开始时间作为 `evaluatedAt`。现改为完整读取快照后再取 PostgreSQL `clock_timestamp()`；新增真实数据库屏障，在列表 `BEGIN` 后、首次快照前提交新邀请，断言新事实可见且 `evaluatedAt >= createdAt`。PostgreSQL 检查扩展为 19 项，仍待同一窗口最终确认。

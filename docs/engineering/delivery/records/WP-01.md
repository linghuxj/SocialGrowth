## 当前阶段范围

- `product/contracts/src` 作为 TypeScript 运行时契约源，严格拒绝未知字段；生成版本化 JSON Schema 供 Kotlin/Python 交接。
- `product/backend/migrations/0001_identity_and_device.sql` 仅建首批权威对象，用唯一约束、检查约束和部分唯一索引建立并发保底。

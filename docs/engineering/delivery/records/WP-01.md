- 新增 PostgreSQL 事务服务，不开放 HTTP 路由；路由与会话认证仍由 WP-02～05 集成。服务显式接收已认证的 registration/provider/installation context，不用请求体 ID 充当权限。
- 注册事务锁定手机验证和邀请，复核 purpose/过期/消费/配额，在同一事务创建 provider、邀请消费、扣次、验证消费、幂等结果和审计。
- 关联会话创建原子失效旧会话并持久设备标签；扫码读取在校验 provider 后只返回必要目标。确认事务锁定 provider/session/installation，原子创建设备归属、消费会话、保存幂等结果和审计。
- 幂等摘要排除可随重试变化的 `requestId`；同键同业务载荷返回原结果，同键异载荷拒绝。认证/状态检查仍在返回原结果之前执行。
- 真实 PostgreSQL 17 集成测试必须同时提供专用 URL 和 `SG_PRODUCT_TEST_ALLOW_RESET=1`，没有默认数据库；测试前后重建/删除专用 schema。
- 首次实现的 5 项真实数据库检查通过：末位邀请名额并发只一个成功；同号并发只创建一个 provider；注册丢响应式重试返回原结果且不重复扣次，同键异载荷拒绝；关联会话替换/读取/确认/重试与审计一致；单次关联会话的两提供者竞争只一个成功。

本阶段仍未验证 HTTP 认证/授权、短信供应商、真实 Web/Android 业务页面、Kotlin/Python 消费、真实扫码或旧客户端兼容；这些边界不由后端事务子范围的通过结论覆盖。

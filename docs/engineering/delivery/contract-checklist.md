# 跨端契约交接清单

更新：2026-09-29。以下是实现前及评审时必须回答的工程问题，不是另一个业务需求版本。由工作包主责在 `product/contracts/` 或对应模块文档形成实际字段、schema、状态表与时序，引用 CT 编号；无需先写完全部系统契约。未落地项不能因为本清单存在就打勾。

## 所有契约共用的交接要求

- [ ] 明确权威写入方、调用者身份、可见字段、对象归属与授权范围；客户端提交的 providerId、deviceId、actorId 不作为权限证明。
- [ ] 明确请求/响应/事件格式、必填/可空含义、时间单位及时区、版本、未知字段与不兼容版本处理；Kotlin/Python/TypeScript 输入均运行时校验。
- [ ] 明确请求标识的作用域、有效期和幂等记录保留方式；同一键不同载荷拒绝，重试返回原结果，授权已失效时不能借重放读取原敏感结果。
- [ ] 业务写入、配额消费、唯一性及待投递记录的事务边界可审查；先查后写不能代替并发约束；外部网络调用不占数据库长事务。
- [ ] 区分已受理、已生效、外部事实待确认、明确失败及可重试；网络超时不能推断未执行；提供原请求结果查询或重试接续方式。
- [ ] 每种迟到事件说明关联原对象、忽略/记录/补偿规则；检查当前归属、代次和撤权，不覆盖新状态。
- [ ] 给出正常、错误、冲突、超时未知、重复、乱序、撤权、进程重启示例；标注可观察事实、审计字段和不得出现的秘密。
- [ ] 生产方与每个消费方复核，QA 关联 AC 用例；接口变化记录影响的任务、迁移、旧客户端及回滚，不能仅改一端类型后宣称兼容。

## CT-01 三类身份与管理会话

主责 WP-01/02/04/06；BE 牵头，WEB/AND 复核；AC-01/02/04/08/09/58/60。

- [ ] 运营身份、提供者管理身份、设备本机身份分别认证；运营同权，提供者只本人，本机只自身接入/必要状态/暂停，不可恢复、退出或读完整管理资料。
- [ ] 服务端校验所有读取、写入、文件链接和请求结果查询；不能只在 UI 隐藏入口。
- [ ] 登录凭据、会话保存、续期、到期、退出、停用、密码恢复与撤销的实际机制及参数确定；Web 跨站请求保护、Android 安全保存和日志脱敏依实际传输方式实现。
- [ ] 首个运营账号初始化幂等；并发停用不造成最后一个有效账号消失；初始化不是任意新增人员的绕过页面入口。
- [ ] 停用与写请求竞争时定义事务生效顺序；停用后不再授权新操作，已受理外部副作用另保留事实，不宣称可撤回已发生动作。
- [ ] 管理退出只终止相应管理访问、清理缓存及拒收迟到敏感结果，设备执行凭据/参与意愿与已受理控制请求保持；重登读取原事实。
- [ ] 原号码不可用的人工换绑必须核验本人、验证新号、保持原身份及历史；不新增完整找回工单产品。运营密码恢复保留受控维护记录。

## CT-02 邀请、短信与注册事务

主责 WP-03/04；BE 牵头；AC-03～05。

- [ ] 同一邀请的码/链接共用人数上限、已用名额、有效期与撤销状态；创建者可追溯。过期按中心权威时刻判断，边界一致。
- [ ] 短信发送、验证码通过、注册成功是三个事实；短信结果绑定号码和用途；错误/过期/重发/限流/供应商超时分别处理，验证码不进入截图或 trace。
- [ ] 最终注册在同一事务中核验邀请与剩余额度、验证结果可用性、手机号唯一性、创建身份及扣减名额；失败回滚。最后名额与同号码双竞争都测试。
- [ ] 验证成功后邀请被撤销/耗尽/到期，以最终事务为准；旧页面显示有效不代表最终可注册。
- [ ] 注册已成功但响应丢失时查原身份及结果，不再次扣次；已有身份登录、新增设备不消费邀请，邀请失效不撤销既有身份。
- [ ] 运营复制邀请由现有方式发送，不实现自动邀请群发；注册真实短信通路仍需独立落实。

## CT-03 安装身份、设备与扫码关联

主责 WP-05/08；AND+BE；AC-06/07/08/12。

- [ ] 业务设备 ID、App 安装身份、管理手机、网络节点与 ADB 目标分别建模；IP、端口、名称和单次关联码不是稳定设备主键。
- [ ] 未关联入口仅授予本机准备能力，登录管理不自动接入本机；获取关联码不依赖尚未准入的 Tailscale。
- [ ] 管理端扫描后先看必要目标信息并明确确认；未确认不写归属，不暴露另一提供者信息。
- [ ] 同一事务消费单次关联会话、检查目标当前归属/交接、写唯一关联及请求结果；重复提交接续原结果，同键换目标拒绝。
- [ ] 新关联会话产生后旧成功迟到不能覆盖新会话/归属；关联结果丢失可查询，不凭客户端超时生成新设备。
- [ ] App 重启续用持久安装身份；重装/清除数据无法证明旧关系时保留待核对，不能自动解除暂停/退出或认领旧设备。

## CT-04 状态读取、错误与页面接续

主责 WP-06/12/20；BE+WEB+AND；AC-08/09/10/23/57。

| 事实 | 页面必须展示 | 不允许的推断 |
| --- | --- | --- |
| 关联已确认 | 同一设备、所属本人、待完成接入 | 已在线或可执行 |
| 请求已提交但中心未确认 | 结果待确认，提供查询/接续 | 已暂停、已退出或重建请求成功 |
| 中心停派但在途未结束 | 已受理，停止待确认 | 手机可交给现场处理 |
| 已确认停止但远程接管未交还 | 等待交还及下一步 | 已取得现场独占控制 |
| 现场说明已保存 | 仍暂停，需本人明确请求恢复 | 自动解除暂停 |
| 任务执行结束、发布未知 | 执行结束／发布待核实 | 成功或可重发失败 |
| 来源未返回指标 | 未取得、延迟或权限不足及时间 | 零值 |

- [ ] 所有页引用同一对象/请求/版本；客户端缓存返回不得覆盖更高版本事实，刷新不会重复提交。
- [ ] 返回、切设备、关闭对话框、退出登录不撤销已受理请求；未提交的取消与已受理后的离开分别实现。
- [ ] 错误码映射为可读原因及下一步，说明由本人/运营/系统处理；不把技术栈暴露为产品操作负担。
- [ ] 存在未保存输入、部分失败、他人更新时有确定接续；跨页过滤、焦点和必要定位保持。

## CT-05 接入、配对及端点协议

主责 WP-08～10；EX+AND+BE；AC-11～15。详细约束沿用[当前对应说明](../../android-pilot-onboarding.md)，本清单不将草案数值提升为生产指标。

- [ ] 受认证引导 → 先建立受限策略 → 独立核验入口 → 实际来源/持钥挑战 → 正式权限应用及核对 → 中心配对/目标核验，各自有状态及失败回收。
- [ ] 受限访问的拒绝矩阵包括 ADB、其他手机、运营后台、业务出口；检查其他规则的叠加授权及可信代理链，不能先开全网再收窄。
- [ ] 挑战绑定接入、安装/设备、节点、用途、时效和代次，原子消费；网络凭据撤销与已连节点回收分开，超时保留回收待处理。
- [ ] 管理机手输系统配对码绑定设备、中心主机、当前端点及会话；并发配对逐台隔离、同机互斥，迟到授权副作用单独核实。
- [ ] 配对端口和连接端口分开；上报完整快照、安装启动代次、单调序号、报告标识、端点类型/来源、新鲜度、撤销状态；请求与结果均绑定当前设备。
- [ ] App 独立认证上报；中心只连接当前可信绑定目标；不能把通过既有 ADB 拉取诊断报告当成独立上报。
- [ ] 心跳、端点新鲜度、动作许可三种时间分别处理；失效端点立即退出执行条件，不等心跳阈值。
- [ ] 正常变化只更新记录；失败或需人工才待办提醒；维护重连不恢复参与意愿、不绕过任务恢复预算。

## CT-06 设备控制与动作许可

主责 WP-11/12；EX+BE+AND；AC-16～20、22、59。

- [ ] 分别保存设备连接、参与意愿、项目/账号暂停、授权、控制持有者/代次、在途动作、提交结果；“online”不得承载全部许可。
- [ ] 每条真实手机读取和动作路径在实际调用前核验当前授权、代次、用途和期限；控制服务不可达拒绝新动作，禁止备用 ADB 路径绕过。
- [ ] 定义许可检查与动作开始的竞争处理：已发出的动作保留在途事实，停止请求使后续许可失效，不承诺撤回已到平台的调用。
- [ ] 提供者暂停含读屏/采集/核验；项目暂停仅阻止发布，允许满足其他条件的历史采集；恢复核验仅允许必要身份/状态/未决结果检查，不开放日常发布。
- [ ] 离线本机暂停先持久保存意愿，重连先同步；中心旧恢复、心跳或任务消息不得覆盖较新的暂停。无法证明本地阻止动作时保持实际停止未知。
- [ ] 请求受理、停派、后续动作被拒、在途结束、实际停止、交还、恢复分别有证据；进程退出/超时/取消/锁到期均不足以独立证明真实停止。
- [ ] 人工远程接管与现场协助均核对独占条件；浏览器断开不自动交还，交还后重新核验当前界面与发布事实。
- [ ] 退出以系统受理并停派时点结束承接，实际停止/网络撤权/登录清理分别追踪；旧恢复、晚回执和重连不重新启用。

交接时必须画出或列出六条交错序列：暂停对在途动作、离线暂停对旧恢复、恢复核验中再次暂停、退出中收到配对成功、远程接管对本机现场协助、旧执行器失联后重新上线。每条写明中心/手机/执行器看到的版本及拒绝点。

## CT-07 任务、队列与外部副作用

主责 WP-16/18/19/21；BE+EX；AC-29～31、37～43、59。

- [ ] 一份权威任务关联项目、批准/安排/素材/分配版本、设备、平台发布身份、名额、依赖、窗口、任务尝试和恢复预算。
- [ ] 任务变更与待投递记录同 PostgreSQL 事务；发送确认丢失允许重复消息，消费者按业务事实去重并重新校验许可。
- [ ] 列出事务提交前、提交后投递前、投递后确认前、领取后动作前、提交平台后回执前的崩溃处置；分别验证，不用队列 completed 作为平台成功。
- [ ] 可能提交平台前保存提交意图。存在意图而实际结果未知时只核实，不重发；查询无法确认时保留未知和原名额。
- [ ] 恢复累计按一轮执行最多 2 次／5 分钟的可配置规则持久记录；故障类型、端口、进程或消息重试不清零；人工介入后的新轮次须有交还／复核依据。
- [ ] 项目结束、素材撤回/更正、交接与排程竞争时，开始执行前再次核对当前版本；已经进入发布流程/提交未知不被普通安排直接替换。

## CT-08 素材、发布与证据

主责 WP-15/18/19/21；BE+EX+WEB；AC-27～29、33～43。

- [ ] 内容身份与文件哈希区分，语言/重导入/形式切换共享平台名额，连载账号和分平台依赖不被重试重置。
- [ ] 对象引用包含原存储位置、哈希、业务归属与访问范围；切换 S3 配置不重新解释旧引用；本地 MinIO 与正式使用能力分别验证。
- [ ] 任务文件版本、传输完成、手机可选取及实际选取分别留证；撤回/更正后的旧文件不能进入新的发布尝试。
- [ ] 平台核验需匹配发布身份、内容及可取得的标识/链接和时间；标题相同、最新一条或引擎完成均不充分。
- [ ] 密码/验证码/令牌在截图、屏幕文字及工具响应进入模型前保护；无法保护则转人工；文件/证据下载不能跨提供者泄露。

## CT-09 反馈、周期与业务 AI

主责 WP-17/22～24/26；AI+BE；AC-32、44～49。

- [ ] 建立指标字典：来源权限、单位、内容/账号粒度、区间、原始时区、实际截止、采集时间、缺失原因和更正关联；真实零与未知分开。
- [ ] 累计快照不相加，账号指标不硬拆内容，页面/模型只使用可比证据；更换来源或定义保留生效范围。
- [ ] 周期左闭右开，运行变更从当前结束同一时刻连续接续；时区/DST、迟到核验、原周期最低数及不跨期重复计数有明确样例。
- [ ] 精确发布后窗口与完整统计日窗口分别定义；长度、覆盖、偏移、年龄和比较资格可核对。
- [ ] 真正调用业务模型，记录受控输入/结构化输出/简明理由/校验结果，不采集内部思维过程；模型无权写成功、取消暂停、提预算或改分佣。
- [ ] 每次复盘连接事实→建议→生效安排→实际执行→后续反馈；维持原计划不复制任务，数据不足暂停相关优化而非全局停发。

## CT-10 承接、收入、分佣与恢复

主责 WP-13/21/25/27；BE+OPS；AC-21、43、50～53。

2026-10-01 [WP13筹备子阶段](records/WP-13.md)：运营声明媒体账号/Page/频道来源引用与初始预留HTTP已接实际AppModule，新增四strict共享schema/0022命令journal，作者14实际HTTP-PG及旧资源13PG通过。登记registered_unverified、预留pending_initialization、actionPermissionGranted/acceptanceStarted固定false；同guard/原会话-CSRF/版本/原key重放不覆盖身份。BE交EX/WEB/AND消费职责，原固定非作者与QA门禁待签，真人消费者确认仍待实际；未实现受控凭据/逐身份Artemis核验/有效承接producer。下列承接与恢复验收项不因此勾选。

- [ ] 承接起点按逐账号初始化/身份核验/执行就绪，终点按退出受理停派；暂停/掉线不截断。交接事实与收入时间粒度独立核对。
- [ ] 收入以产生期间和来源记录标识归集，到账是可结算条件；比例按历史生效期间匹配；明确金额精度、币种及舍入，不猜测兑换或跨币种相加。
- [ ] 无人承接与资料缺失分开；跨边界无法可靠拆分保持待核对，不均摊，不整体归公司/前任/后任；重复导入、补录和更正不重复计佣。
- [ ] 预估、可结算、已付事实独立；本人端只看本人必要信息；基础处理记录不冒充真实付款。
- [ ] 备份恢复覆盖业务库、待投递记录、队列、对象引用及凭据撤销事实；恢复时先停消费并核对更新的外部/设备事实，再决定可恢复任务。
- [ ] 不兼容客户端、不可逆迁移和已发生的平台副作用分别有回退/前向修复方案；回滚代码不能撤销已经公开的内容。

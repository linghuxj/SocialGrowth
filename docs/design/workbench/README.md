三张图由内置 Image Gen 生成，使用虚构的 2026-09-28 项目控制场景，日期不代表本轮实际操作时间。暂停后可以选择按条件恢复，也可以正式结束；结束稿不是恢复稿之后已发生的事件，结束也不要求必须先暂停。

已检查：暂停请求与在途确认分开；结果未知保留核实入口，没有重发捷径；恢复列出 1 项待排期、1 项过窗、1 项提交未知，未把它们标成全部发布成功；结束前列出两个确认未提交的拟取消任务和一个继续核实的未知任务；收尾期限标为示例配置，资源及平台内容不自动清理；结束按钮与返回动作区分。主要内容未明显裁切。

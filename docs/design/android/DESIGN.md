# SocialGrowth Android 设计规范

> 文档用途（2026-10-06）：保留已确认的页面和视觉约束，未实现要求仍有效。实际页面与接线见[当前实现](../../current-implementation.md)；本文件不是已实现清单或运行证据。旧图片和原型不作为当前操作入口。

更新：2026-10-04；版本 0.7。适用设备提供者 Android App。用户按 AND-006 选定[首页第 1 版](home-action-v1.png)的视觉方向，AND-010～025 进一步对齐并确认全部 11 组页面的 UI 与交互规则；本文件将其落实为可检查的设计规格，具体数值是设计建议，仍需原生渲染验证。业务以[当前需求基线](../../current-requirements-summary.md)及[页面规格](../../android-app-page-spec.md)为准。

## 1. 设计意图

让提供者先知道哪台手机需要自己配合，再清楚地完成接入、暂停、现场处理和恢复。本人设备及协助是首页主体，分佣有独立入口。浅灰底、白色设备列表与浅琥珀协助区域区分信息层级，蓝色强调下一步动作。

首页采用已选的“协助提示在上、设备列表在下”结构；有协助事项时保留一项最需要当前用户处理的主动作，其余事项可进入列表查看。正常状态不显示空警告；等待运营、等待回执和需要本人行动分别表达，不把所有阻断都设计成需要点击处理的警报。

按 AND-013，在同等可行动且无更紧急风险的条件下，主提示优先原有手机故障，新手机接入进度仍在对应设备处可达。该优先级用于安排提示，不自动发起恢复，也不将用户主动暂停显示成故障。

不把运营工作台的多列布局、项目资料、素材和逐条发布明细搬到提供者端。使用平实的状态与动作文字，不承诺始终在线、立即停止、自动获得权限或确定收益。

按 AND-017，首期设计以完成核心业务为限，不增加主动求助入口、表单或其进展页面。必要说明、直达操作、检查与重试仍需清楚呈现；能在原页面表达的状态不另建页面，已确认的功能保持，不以视觉完整性为由扩充范围。

## 2. 色彩建议值

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 主色 | `#2459C4` | 主动作、当前导航；使用纯色，不以渐变提高视觉优先级 |
| 页面底色 | `#F4F6FA` | 一级页面及详情画布 |
| 内容底色 | `#FFFFFF` | 设备列表、条件明细和流程信息 |
| 正文 | `#172B4D` | 设备标识、标题、主要说明 |
| 辅助文字 | `#526176` | 说明、时间和次要标签，不承担唯一的关键警示 |
| 分隔线 | `#DCE2EA` | 内容分组与列表行，不单独作为控件唯一边界 |
| 需配合文字／底色 | `#8A4B08`／`#FFF4DF` | 待本人处理和需关注的确认缺口 |
| 通过文字／底色 | `#146C43`／`#EAF6EF` | 有实际证据的通过或可用条件 |
| 错误文字／底色 | `#B42318`／`#FFF0EE` | 已确认失败或危险操作的必要提示 |

暂停和等待不是失败，优先用中性文字；在线不使用整张绿色卡片暗示设备可执行。每种状态同时有文字，不能仅凭颜色或圆点区别。界面需要多种事实并存时保留独立行，不压成一个颜色标签。

上述确定色值组合已进行对比度计算：白色／主色 6.36:1、正文／白色 14.10:1、辅助文字／白色 6.31:1、辅助文字／页面底色 5.83:1、需配合文字／底色 6.23:1、通过文字／底色 5.81:1、错误文字／底色 5.93:1。计算用于检查建议值，不证明生成 PNG 或实际 App 使用了这些精确颜色；渲染后仍须核对。

## 3. 字体、间距与可点击区域

采用支持中文的 Android 系统无衬线字体，不绑定特定厂商字体或添加装饰字体。文字采用 sp，布局采用 dp；390 × 844 是设计参考视口，不是支持设备或固定屏幕尺寸的承诺。

| 元素 | 建议起点 | 约束 |
| --- | --- | --- |
| 首页大标题 | 28 sp，较粗 | 设备详情的大设备标识可同级；字体放大时允许换行 |
| 分组／状态标题 | 20 sp，较粗 | 关键状态不压成小标签 |
| 正文及主动作 | 16 sp | 原因、操作目的及下一步保持易读 |
| 行标签与辅助说明 | 14 sp | 不用浅小字承载停止未确认等重要事实 |
| 日期及示例标记 | 13 sp | 仅辅助信息，保持充分对比 |
| 页面左右留白 | 16 dp | 小屏优先换行和纵向滚动，不缩小文字塞入 |
| 区域内部留白 | 16 dp | 同组元素间隔 8～12 dp，主要区域间隔 16～24 dp |
| 主按钮高度 | 至少 52 dp | 放大或多行时允许增长；不挤占系统安全区域 |
| 图标与行操作触控区域 | 至少 48 × 48 dp | 图标本身可小于触控区域，相邻区域不可互相覆盖 |
| 表面／按钮圆角 | 12 dp／8 dp | 不叠加多层圆角卡片；使用轻量分隔组织列表 |

最低触控尺寸与文字对比度参考[Android 官方可访问性指导](https://developer.android.com/guide/topics/ui/accessibility/apps)，已在 2026-09-28 核查。字体放大、读屏顺序、焦点、对比和小屏适配都需要在实现后测试，静态图只能用于视觉审阅。

## 4. 导航与组件

| 组件 | 固定内容与行为 | 典型状态 |
| --- | --- | --- |
| 首次使用方式入口 | 两张同等醒目、同样大小的白色卡片纵向排列；上方“管理我的设备”，下方“接入这台执行手机”，各含用途说明和进入箭头，整卡可点 | 结构与视觉主次按 AND-010 确认；使用浅灰画布与蓝色强调，轻量按压反馈，不把用途选择画成已完成关联或授权 |
| 一级导航（AND-025） | 设备、分佣、我的；标签与图标一起显示；各一级与次级页面内不再放置冗余的“返回首页／返回设备”按钮，由导航直接切换 | 当前项用蓝色和形态区别；分佣使用账单／记录语义图标，不使用人员或提现图标 |
| 首页与设备列表（AND-023／025） | 顶部行动提示、参与中设备列表、底部“已退出设备 · N”折叠区；首页移除原退出登录按钮（收拢至“我的”） | 折叠区默认折叠，展开可查看历史设备与清理进展；清理需配合的已退出设备置顶提示 |
| 协助提示 | 设备标识（优先备注名）、需要本人做什么、一个明确的下一步 | 需本人处理、已提交待复核；后者不继续显示催促处理按钮 |
| 设备行 | 备注名／型号／识别信息、业务状态、连接或授权提示、已知更新时间 | 就绪、待协助、暂停、失联、退出；同一用户的手机逐台呈现 |
| 条件明细 | 每个条件独立一行，事实与核对时间可追踪 | 网络在线、授权待恢复、暂不可接任务可同时成立 |
| 主按钮 | 表达当前页最重要的一个动作 | 查看步骤、确认关联、暂停本机、请求恢复；不能复用“完成”隐藏不同语义 |
| 进展列表 | 已受理、停新派发、旧端停止及复核分别呈现 | 未知显示等待，不显示虚构百分比或估计完成时间 |
| 永久退出入口 | 指定设备详情内独立文字入口及确认页 | 不紧贴刷新，不以删掉卡片代表退出或清理成功 |
| 时间说明 | 最近一次事实确认时间 | 页面刷新不更新成事实时间；跨日期或歧义时给出日期／时区 |
| 注册表单 | 按 AND-011 在同页依次放邀请输入／状态、手机号、短信验证码、明确发送与注册动作；手动填码或链接自动带入 | 邀请通过、发送受限、字段错误、注册处理中分别表达；错误靠近对应字段，空字段点击提交先就近提示，不发注册请求 |
| 手机号登录 | 按 AND-012，无邀请链接的管理入口默认进入登录；沿用注册表单视觉，展示手机号、短信验证码及“登录并进入管理”，保留受邀注册和原手机号不可用的帮助入口 | 切换认证用途不自动发码或提交；字段错误就近反馈，登录成功才进入本人设备首页，不改变执行手机状态 |
| 关联确认 | 本人身份、脱敏手机号、目标设备标识、可选设备备注名（AND-014）与确认动作 | 已识别不等于已关联；未来准备步骤为说明行，不附可跳过确认的导航箭头 |
| 设备备注名 | 按 AND-014，关联核对时选填，设备详情可修改；首页、协助和详情优先显示，型号与稳定标识仍可核对 | 未填不阻挡关联，未设置时用型号及标识；长名称换行，改名不改变设备身份或请求对象 |
| 现场协助与修复引导 | 按 AND-021／022，两端分工：管理端看问题与停止确认；执行手机展开逐步引导（AND-016），就地检查通过后管理端直接出现“请求恢复／暂不恢复” | 彻底废除手动文本“提交处理结果”表单；自动检查通过仍须在管理端明确“请求恢复” |
| 恢复前提示 | 指定设备仍暂停、恢复后将检查的条件、请求恢复和暂不恢复 | 将来要检查的条件不打通过勾；现场检查通过不等于解除暂停 |
| 分佣记录（AND-024） | 顶部仅保留“平台预估收益”参考区，下方按期间逐条列出记录；**无汇总金额** | 平台预估收入独立说明，不合并余额；缺数据为待核对，已付须有实际依据 |
| 分佣依据 | 本人承接期间、可归属到账收益、适用比例及期间、计算与付款事实 | 比例未定不计算确定佣金；不显示其他提供者或公司全量财务 |
| 永久退出确认 | 目标设备、影响范围、停止与清理边界、保留历史的说明 | 仅此页确认提交动作采用危险色，返回不提交；受理后不能用返回撤销 |
| 退出进展 | 受理、停派发、旧端停止、清理分别呈现 | 离线时保留未知事实，不用整体成功勾或普通恢复按钮 |
| 本机关联码 | 本机标识、有效会话的二维码、按 AND-015 新增的可手动输入设备关联码和等待管理手机确认 | 两种形式对应同一目标与会话；示意图不用于实际接入，失效后按实际状态更新，不凭用户自报已扫码／输入通过 |
| 手动输入设备关联码 | 添加／扫码页可达，说明码来自执行手机；输入后“核对设备”，进入共用关联核对页 | 不索取相机权限，不要求先扫码失败；输入有效不自动关联，错误、失效与尝试受限分别反馈 |
| 本机准备引导 | 按 AND-016 保留整体进度，重点展示当前一步；用途、操作及检查说明默认可见，能直达的设置、官方下载或应用页面必须提供可点击入口；最后一步单次明确表达“开始参与”（AND-018） | 无法直达时提供实际可用的上级入口和剩余手动步骤；返回后核验事实，管理手机不代开执行手机权限 |
| 接入条件检查 | Wi-Fi、管理连接、调试授权与中心连接、业务网络分别呈现 | 显示实际检查时间；部分通过、等待运营和整体可接任务区分 |
| 本机状态（AND-018～020） | 顶部粗粒度使用状态（使用中/空闲/无法确认；通知栏常驻提示）；单一“暂停本机”控制（无参与开关）；说明去管理机恢复 | 顶部状态仅为现场提示；不展示任务内容；暂停前弹出底部确认浮层（AND-019） |
| 本机暂停确认浮层（AND-019） | 底部弹出，核对本机标识，说明停止接任务及去管理端恢复，点“确认暂停”提交 | 取消不产生请求，防误触，不要求理由/验证码/审批 |
| 本机暂停进展 | 本机记录、中心受理、实际停止分开 | 未送达或停止未知不显示已暂停成功，不提供现场可开始保证 |
| 我的页面（AND-025） | 本人身份、脱敏手机号、设备接入说明、账号帮助、退出管理登录（不影响执行机） | 首页退出登录收拢至此；无冗余返回按钮，依赖底部导航切换 |

详情及协助页面建议用顶部返回保留原设备上下文，隐藏一级底部导航以减少现场操作过程中的误跳。返回后恢复原设备列表位置；离开详情不撤销已受理请求。该导航细化属于所选视觉方向的设计建议，不增加业务权限。

本机引导也保留明确返回上下文；已关联的准备、检查、等待运营页面须可进入“本机状态”及本机暂停，无需完成全部授权。关联码页未关联时不展示管理动作。本机暂停页面不放恢复和永久退出按钮，说明改用已登录的管理手机。状态明细行的箭头只在实际有只读详情或获准引导时使用，不暗示点击自动修复权限或切换网络。

按钮进行中时显示动作进展并防止重复提交，但应允许查看详情或返回；后续请求核对同一次操作结果。列表和页面刷新不改变用户指下的目标设备，不用乐观反馈提前声明停止或恢复成功。

财务参考信息与正常未付款状态使用中性说明；预估收益不是异常，不因尚未付款自动显示危险警报。分佣状态使用文字表达付款事实，绿色仅能表示已核实条件，不能暗示已支付。详情中的金额或比例采用示例时，在金额附近明确标记；生产页面不沿用示例数据或示例说明。永久退出确认与进展可显示已知状态变化，不将两张静态图推定为经过实测的连续流程。

## 5. 关键文案与业务事实

| 应显示的文字 | 所代表的事实 | 不能表达成 |
| --- | --- | --- |
| 可接任务 | 当前执行条件满足 | 正在执行、已产生收益 |
| 邀请已校验 | 当前邀请资格检查通过 | 手机号已验证、已注册 |
| 已识别关联码 | 已取得待核对目标 | 已关联、已授权、可接任务 |
| 本机条件检查已通过 | 当前本机准备条件满足 | 运营已分配、初始化已核验或开始接任务 |
| 调试授权与中心连接待确认 | 实际中心执行路径尚未证明获准可用 | 只因系统开关已开启就标记全部授权成功 |
| 本机已记录暂停请求 | 本机保存了待确认暂停意愿 | 中心已停派或手机已停止 |
| 调试授权待恢复 | 该项条件缺失 | 手机已永久断开、整个系统失败 |
| 请求已受理 | 中心收到这次请求 | 手机已停止 |
| 已停止新任务派发 | 中心不再向目标机派发新任务 | 当前动作或平台提交已撤销 |
| 等待停止确认 | 旧端停止尚未确认 | 可以现场操作 |
| 已确认停止，请按步骤处理 | 停止及控制条件已有确认 | 获得公司账号管理或发布权限 |
| 设备仍保持暂停 | 提供者还没有明确请求恢复 | 保存说明后自动恢复 |
| 正在复核，尚未恢复日常任务 | 已明确请求恢复，正在核验 | 已恢复、自动补发旧任务 |
| 平台预估收益 | 来源给出的广告收入估计 | 本人佣金余额或可提现金额 |
| 可结算·未付款 | 佣金依据与计算成立，尚无完成付款事实 | 款项已到账提供者 |
| 已付 | 有实际付款完成依据 | 仅记录已生成或内部处理已完成 |
| 退出请求已受理，手机停止尚未确认 | 退出意愿已记录，旧端事实未知 | 设备已清理或全部处理完成 |

“查看处理步骤”只进入说明；在步骤中明确发起暂停并等待确认。处理结果提交与请求恢复分开表达；恢复后仍检查其他暂停、接管、撤权、任务有效性和未知结果。页面按钮的出现或消失不能代替实际授权检查。

## 6. 首期范围与页面参考

按 R-141 停止增加组件及页面范围。“我的”仅需本人身份、脱敏登录号码与必要帮助，沿用现有信息卡和说明行。人工找回按 R-140 保留原身份及历史；相关图稿为参考，不要求首期实现完整找回表单、工单和进度组件。退出管理登录按 R-142 不影响执行手机；图示仍不代替会话失效及设备状态保持的实际验证。


当前参考包括所选首页原稿及管理流程、本机关联码、准备、条件检查、等待运营和本机暂停图稿，见[图稿索引](README.md)。原稿用于追溯选择，修订稿消除不准确文案和图标；生成图不锁定精确 token，偏差以本文件与业务规格校正。

原生实现前后应核对：首页无待办与多个待办、三台设备各自状态、长设备名称、放大文字、验证码错误／受限、关联结果未知、暂停请求未送达／旧端未确认、恢复仍有其他阻断、退出清理未完成及数据缺失。Web 联动按仓库规定用 Playwright 真实页面操作；App 授权和真机恢复另留实际环境证据。

## 本机接入与暂停检查

五张新页面分别独立调用内置 Image Gen，并附入已检查的首页修订图作为风格参考；检查页随后以自身 v1 为实际参考做单处文字修订，沿用同一方向。提示词随图保存，不包含真实关联、网络或系统授权凭据。

- 关联码页保留“等待管理手机确认”，示意码明确不可用于接入；没有仅凭扫码便显示执行资格或管理会话。
- 本机准备页说明手机操作授权用途，Wi-Fi 已连接与配套待设置、调试待完成同时存在；从设置返回须以检查事实为准。
- 分项检查页中两个通过项未覆盖调试授权与业务网络的待确认／未检查事实。v1 把待确认概括成“还需完成调试授权”，因此修订为 v2 的“调试授权仍待确认”；[v1](local-condition-check-v1.png)只作修订追溯。
- 等待运营页的通过只指本机准备，不代表首次分配、初始化核验或日常任务已经开始；未出现让提供者选择公司项目、账号或催促运营的入口。
- 本机暂停页只将本机已记录勾选完成，中心与手机停止保持未知；没有要求重新登录，也没有在设备身份下放出恢复或永久退出按钮。需要实际测试保存失败、断网、重启及重连，图稿不证明离线强停能力。
- 五张页面未见主体裁切或明显乱码，均无完整管理底部导航和其他设备／分佣资料。图中的同一编号用于说明各状态分支，时间为独立示例，不能拼成暂停后自动恢复的真实轨迹。
- 准备和检查图未画出完整的本机状态页；实施时须按规格保留可达的本机状态及“暂停本机”入口。各明细行箭头仅能打开实际存在的事实详情或授权说明，不能点击即自动改权限。生成色彩过渡仍应落实为规范纯色，字体放大与小屏滚动待原生验证。

## 基础分佣与永久退出检查

- 分佣列表将 9 月预估广告收入 USD 80.00、8 月可结算且未付佣金 USD 30.00、7 月已付佣金 USD 18.00 分开，没有相加为余额。月份不代表已经选定月结规则。
- 分佣详情与列表的 FB Page·021、SG-021 和 USD 30.00 一致；8 月收入于 9 月到账，仍展示 8 月所属期间。示例比例标注可见，算式正确，未出现提现、绑卡或付款动作。
- 退出确认只指向 SG-028；进展图只将受理及停止新派发勾为完成，旧端停止与登录清理分别保留等待，不展示恢复或撤销已受理退出。两图是独立状态快照；确认图的连接在线不证明之后一直在线，也不构成真实流程证据。
- 四张图未见主体裁切或明显中文乱码，尺寸均为 853 × 1844。分佣详情较密，原生实现必须允许滚动和放大文字，不能通过缩小字号把全部依据挤在一屏。
- 生成偏差：预估收入和普通未付款提示用了琥珀色与感叹号，应按设计规范改为中性说明；未付款本身不是异常。分佣详情额外使用“应得佣金”字样，实施时统一为“可结算佣金”，避免引入另一个金额口径。
- 生成图未完整表现来源更新时间、比例生效区间及全部状态分支，仍以页面规格为准。退出危险按钮和其他表面存在细微渐变，应使用规范纯色。此处是静态视觉与文案核对，尚无实际支付、退出、清理或真机交互验收。

## 视觉检查与生成偏差

- 三版均可见主动作、三台设备及底部导航，未见主体内容裁切。当前是图片人工检查，不是原生 App 验收。
- 第 2 版自动带入“夏日家居”项目名和 Android 版本示例，不属于提供者首页获准内容或已确认支持范围；后续定稿删除项目名，设备信息只保留必要且实际可得的识别数据。
- 第 3 版将“提交处理结果 → 系统复核 → 恢复”写成过于简略的进展，缺少明确请求恢复及其他阻断检查；定稿必须改为 R-137 的自助暂停、确认停止、现场处理、主动请求恢复、系统复核，不能因图片文字变更业务规则。
- “去执行手机完成授权”是问题摘要；实际处理入口必须先核对暂停和控制条件，不能让首页摘要成为绕过停止确认的操作指令。
- 自动生成的渐变、圆角、图标和提示措辞尚未成为设计规范；选定后统一处理，分佣图标不沿用容易被理解为人员管理的图案。

# Android 客户端采用 Kotlin 原生方案

2026-09-28，用户在 Android 客户端技术方向对齐中选择 A：正式客户端采用 Kotlin 原生方案，覆盖已确认的管理入口和执行手机本机入口。首期面向 Android，系统授权、本机端点发现、网络变化及生命周期处理是核心依赖；相较跨平台界面加原生衔接，直接围绕 Android 能力实现更符合当前范围，代价是单独维护 Kotlin 客户端，无法直接复用 Web 的 TypeScript 页面。

既有 Java 诊断原型及证据按适用范围复用，不视为正式接入闭环已经完成。官方 Tailscale 继续负责 VPN，多设备独立配对会话与并发隔离要求保持；UI 框架、最低系统版本、依赖版本、后台策略及安装更新方式另行落实。选择原生方案不保证后台常驻，认证上报、首次配对、多机及恢复仍按已确认安排在相应模块开发中验证。

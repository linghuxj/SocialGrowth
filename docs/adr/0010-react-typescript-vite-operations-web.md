# Web 运营端采用 React、TypeScript 与 Vite

2026-09-28，用户在 Web 运营端实现方式对齐中选择 A：采用 React＋TypeScript＋Vite，以浏览器渲染的单页应用调用 NestJS 接口，业务规则集中在中心后端。当前首期主要承载内部运营、表单及设备状态交互，相比采用 Next.js 组合服务端与客户端渲染，此方案减少前端服务端渲染部分的维护，代价是自行配套路由、数据请求、加载与错误状态处理，并验证首屏及交互表现。

前端负责展示与交互，后端仍须独立校验身份、权限和业务约束。路由及数据请求组件、UI 组件库、依赖版本、静态文件托管和接口访问配置在对应实现时落实；客户端渲染不锁定独立域名或物理部署。现有 Demo 页面仅按 ADR-0001 评估复用，不自动迁移或覆盖；Web 验收继续通过真实页面使用 Playwright 完成。

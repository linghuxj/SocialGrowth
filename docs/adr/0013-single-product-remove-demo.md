# 只保留一套正式产品

2026-10-06，用户确认删除和迁移相关 Demo，不再维护新旧系统并列入口。保留同一仓库和 `main`／`dev` 分支规范。可运行代码统一到 `product/`，Web 使用同一登录和权限体系；既有执行服务及必要共享规则并入 `product/executor`。取消旧 Web、独立控制器、旧 AI、短链工程和旧接入原型。这样可避免操作人员和验证脚本进入不同系统。

原任务、操作编号、SQLite 状态、设备占用、未知结果、Artemis 私有配置和有效证据保留。中心 PostgreSQL 和执行器本地 SQLite 各自承担原职责，不将保留 SQLite 解释为保留另一套业务产品，也不重放历史任务。历史文档与 Git 只供追溯。此决策替代 ADR-0011 的 Demo 并列维护安排及 ADR-0001 的长期保留 Demo 工程安排，不代表正式发布或全业务验收通过。

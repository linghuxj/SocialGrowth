# 业务后端按模块集中组织，手机执行独立运行

2026-09-28，用户在运行边界对齐中选择 A：项目、设备、素材、任务、反馈和基础分佣等业务由同一个后端按模块组织，使用统一的业务状态与规则；Artemis 手机执行由独立进程承担，通过明确的任务及回执接口与中心衔接，Android App 为独立客户端。相较首期即将各业务模块拆成独立部署的服务，此方式减少跨服务协调和部署环节，代价是业务模块暂不独立发布或扩容，须维护清晰的内部边界。

执行进程可以独立重启，但进程分离不保证同机资源故障完全隔离；资源限额、异常处理和状态恢复在开发中落实。此决策确定运行职责边界，不决定同机／分机部署、服务器数量、Web 发布方式、语言框架、数据库、队列或托管厂商；已有 Demo 目录不自动成为正式部署边界。

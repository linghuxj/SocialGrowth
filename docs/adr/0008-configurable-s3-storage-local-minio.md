# 文件存储采用可配置 S3，本地使用 MinIO

2026-09-28，用户选择对象存储并明确“使用 S3，允许配置。本地使用 MinIO”。正式素材与执行证据通过 S3 接口保存，本地开发使用 MinIO，应用以环境配置连接相应存储；PostgreSQL 保存文件的业务归属、对象引用、哈希与权限。相较依赖应用服务器文件目录，此方案便于应用与执行节点分开部署，代价是维护存储服务、访问权限、环境配置及兼容性验证。

配置覆盖 endpoint、region、bucket、凭据来源及寻址方式，具体配置名在实现时确定；允许配置不扩展为面向提供者的存储管理页面，也不允许普通业务请求指定任意存储端点。凭据由部署环境受控注入，不写入仓库、队列载荷或客户端。正式与本地环境隔离，切换配置不自动搬迁或重解释历史对象引用，历史记录须能定位原存储位置。

S3 与 MinIO 共用存储适配层，所用上传、下载、完整性校验、访问控制及按需采用的分片／签名链接能力须分别验证，本地通过不等于正式环境通过。具体账号、区域、SDK／MinIO 版本、保留期限和备份恢复设置另行落实；本次仅记录实施决定，不创建存储资源或迁移现有文件。

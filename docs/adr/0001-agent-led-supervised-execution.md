# Agent 自主执行与受控人工协作

状态：accepted，2026-09-20 用户确认。

一个运营目标对应一个持续追踪的业务任务；Artemis 负责观察、规划与页面操作，Web 负责下达授权目标、接收证据及人工协助，运行时负责凭证隔离、设备独占、停止和结果未知防重发。拒绝为每种页面穷举坐标脚本，也拒绝仅凭提示词承担停止与权限约束。

短时人工协助在原执行实例等待；进程中断必须保留任务并先重新核验，不重放密码和提交。创建 Page／频道、纠正账号和公开发布不互相隐含授权。当前 Profile 诊断不替代业务 Page 准入。

代价：需要维护 Artemis 受控工具扩展和统一动作入口补丁；升级必须检查旁路及补丁适配。不能宣称所有工具或第三方插件都已自动受控；未经纳管工具默认禁止。

# 建立正式实现主线，按需复用 Demo

2026-09-28，用户在实施方案逐项对齐中选择 A：保留现有 Demo 和历史证据，按照已确认需求建立正式的数据模型、接口与应用结构，并逐项复用适合的组件及既有 Artemis 能力。相较直接在 Demo 中持续替换新旧业务逻辑，此方式需要前期基础工程投入，但能更清楚地划分正式实现与验证代码，避免旧流程及历史数据约束反向决定产品设计。

本决策确定建设方式，具体技术选择以后续 ADR 为准；仓库组织已后续按 [ADR-0011](0011-product-and-demo-in-one-repository.md) 确认为同仓库分目录维护，具体目录见技术设计草案，部署厂商及 Git 分支方案另行落实；也不代表删除、清理或自动迁移现有代码与数据。已取得的有效验证证据继续复用，受变更影响的部分按对应模块补验；设备认证／端口上报／受控重连闭环仍按用户安排在开发过程中验证。

# 正式中心业务数据库从首批开发开始采用 PostgreSQL

2026-09-28，用户在数据库方案对齐中选择 A：正式实现从首批开发开始使用 PostgreSQL 保存中心权威业务数据，包括项目、设备分配、任务、暂停状态和回执等。相较先用 SQLite 再迁移，此方案需要提前配置数据库及备份，但可围绕同一数据库落实事务、约束与并发处理，减少后续迁移和重新验证的工作；正确性仍须由具体实现与测试证明。

本决策适用于正式中心业务数据库，不限定 Android 本地缓存或执行端本地记录。数据库版本、托管厂商、同机／分机部署、备份恢复参数、数据访问组件及任务队列方案另行落实；现有 Demo SQLite 和历史证据保留，不因本决策自动迁移、清理或重放旧数据。

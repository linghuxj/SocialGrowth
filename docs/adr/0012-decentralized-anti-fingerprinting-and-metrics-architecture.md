# 去中心化防关联风控与 FB/YT 效果数据获取架构

2026-10-02，针对 20～50 台分散实体执行手机（每台对应独立固定的海外社媒账号）的防封控安全与真实效果数据获取方案达成一致。为避免中心化资产归集引发的连锁封禁（Cascading Ban）与机房 IP 指纹聚集，系统确立去中心化、物理隔离与拟真行为的核心架构基线。

## 一、 核心决策要点

1. **外链引流安全与域名隔离**：
   - 杜绝全局共用单一短链域名。构建多域名轮换池（Domain Sharding），按项目与设备隔离绑定独立引流域名；
   - 实行两级跳板机制（如 Linktree / 聚合中转），新账号与新发内容前 7 天严格静默外链，正文不挂硬广，置顶外链在自然播放破阈值后延迟追评。
2. **素材分发 1:1:2 黄金模型**：
   - 彻底根除站内重复搬运违规。严格限制：1 份素材 $\rightarrow$ 1 台指定手机 $\rightarrow$ 1 个 FB Page + 1 个 YT 频道，杜绝同平台多账号撞车；
   - 素材分发至手机前执行自动轻量预处理（微调帧率/音轨、消除 EXIF 拍摄元数据），切断底层音视频感知哈希关联；由业务 AI 生成差异化标题与配文。
3. **自动化操作拟人化与轨迹平滑**：
   - 废除固定像素点击。Artemis 点击坐标采用二维高斯随机分布偏移（$\pm 5 \sim 15\text{px}$）；
   - 滑动轨迹采用带有加减速与颤动的三阶贝塞尔曲线，操作步骤间引入 $1.8\text{s} \sim 4.2\text{s}$ 的拟人非对称随机停顿。
4. **全天候生活化行为轮廓与空闲活跃**：
   - 将发帖动作包裹为复合会话：前置 3～5 分钟推荐流自然刷流 $\rightarrow$ 发帖上传 $\rightarrow$ 后置 2 分钟停留与退回桌面；
   - 引入空闲保活排期（`IDLE_WARMUP`）：依据账号目标时区（严禁当地凌晨活跃），在发布间隔随机插入 1～3 次 $3\sim7$ 分钟的自然浏览保活任务；正式发布与人工接管具备绝对优先权，保活任务秒级让步。
5. **数据采集双轨制（公私指标彻底解耦）**：
   - **公开基础指标**（播放量、点赞、评论、公开粉丝）：服务端通过轮换住宅代理发起无鉴权请求（oEmbed / 公开页面轻量解析）批量同步，对手机与账号零风险、零侵入、零关联；
   - **私有深度指标**（秒级留存曲线、受众国家分布、流量来源画像）：严禁用统一 Admin 归集资产或中心机房 IP 集中调用官方 API。改由真机 Artemis 在夜间空闲时段，利用手机本地已登录的 Meta Business Suite / YouTube Studio App 端侧就地快照读取，仅回传脱敏结构化数据，保障物理隔离。

## 二、 影响与约束边界

- 本决策覆盖核心业务自动化串联（C1～C4）以及 WP-11、WP-14、WP-15、WP-16、WP-18、WP-19、WP-22、WP-23。
- 数据存储遵循不可变多版本快照链（`revision + 1`），遇到平台反作弊核减据实记录 `platform_corrected` 状态，不改写历史。
- 授权失效或遇到风控验证码时，采集器立即熔断止血并生成全局待办与邮件提醒，日常发布计划照常推进（遵循 R-046）。

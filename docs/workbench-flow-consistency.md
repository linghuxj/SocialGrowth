## 关键路径

| 路径 | 进入对象与返回规则 | 不同页面必须一致的事实 | 仍需验证的边界 |
| --- | --- | --- | --- |
| 首页待办→详情→关联任务→返回 | 同一项目/待办/任务；恢复原筛选和焦点 | 待办提交、任务复核、设备交还分开 | 他人已处理、局部已解决、列表异步重排 |
| 项目清单→素材/资源/设置→返回 | 返回同项目清单位置，保护输入 | 草案保存/检查/方向批准/就绪分开 | 部分缺项不锁死独立准备，也不授权发布 |
| 方向确认→项目概览→发布列表 | 保留具体批准版本及后果说明 | 已确认不等于已有可执行任务，更不等于已发布 | 版本冲突、确认超时、资源随后就绪 |
| 素材更正→受影响任务→原素材 | 保留新旧文件与业务版本 | 未开始重检，已提交/未知先核实 | 不增平台名额、不改变已有发布事实 |
| 发布列表→核实待办→任务详情 | 同一原任务，不另建一次发布 | 执行结束、平台核验、实际时间分开 | 重复回执、迟到核验、周期归属未知 |
| 任务阻断→设备接管→交还→返回 | 手机、身份和原待办持续可见 | 请求/控制/交还/复核分开 | 同机互斥、失联、提供者暂停、未决发布 |
| 项目暂停→停止进展→关联待办 | 同一项目操作记录，逐任务查看 | 停新发布不等于所有在途均停止 | 离线不能当停止，采集不能绕过手机暂停 |
| 项目恢复→检查→发布安排/待办 | 保留原安排、窗口及前置关系 | 项目暂停解除不等于任务全部恢复 | 已过窗不补发，未知不重发，其他暂停保留 |
| 结束确认→执行进展→收尾报告 | 请求、生效、实际取消和核实分别记录 | 取消未提交、未知核实、资源保留 | 收尾缺数据、收尾到期仍有未决发布 |
| 复盘→变更依据→后续任务→效果 | 原周期评价与后续跟踪范围分开 | 建议/安排/实际执行/新反馈分开 | 可比性、历史更正、后续被另一复盘取代 |
| 设置变更→待生效配置→周期报告 | 生效点接续同一实际时刻 | 当前周期/最低要求与历史口径不变 | 跨生效点保存、时区日期变化、不重复任务 |
| 提供者→设备/承接历史→分佣依据 | 当前设备与历史收入关系分别呈现 | 收入/归属/比例/佣金/已付分开 | 迟到账、多设备不重复计佣、保存不等于付款 |

2026-09-28 补充 R-143：提供者／未分配设备 → 同一全局接入待办 → 处理与首次分配；邀请运营为初始联系人，其他运营可代办，App 对应同一必要进展。尚无项目时不丢弃事项或创建虚假项目，分配后保留原处理记录。R-142 的管理 App 退出登录不改变设备控制事实，运营端不得据此显示设备已停用。

## 共享状态文案

| 已知事实 | 推荐表达 | 避免表达 |
| --- | --- | --- |
| 服务收到暂停请求，部分在途未确认 | 暂停请求已受理；仍有任务待停止确认 | 已全部停止 |
| 解除项目暂停，一部分任务仍受阻 | 项目暂停已解除；任务按条件推进 | 全部恢复成功 |
| 任务条件通过但未到排期 | 待排期执行，并显示原安排 | 已完成/已发布 |
| 有提交动作，平台结果不足 | 结果待核实，显示缺口与原待办 | 失败，请重发 |
| 处理说明保存 | 处理记录已保存；待复核 | 问题已解决 |
| 手机交还已确认 | 已交还；恢复复核中/结果逐项列示 | 手机和所有任务已恢复 |
| 结束请求已受理，取消和停止仍在进行 | 结束处理中，分列停止/取消/未决核实 | 全部结束并清理完成 |
| 收尾报告存在数据缺口 | 报告已形成，保留缺失与局限 | 效果为零或全部核清 |

文案根据实际事实组合，不锁定为单一数据库状态机。正常等待、异常阻断与事实未知分开；颜色只作辅助，原因与下一步须可读。

当前实现与真实验证范围见[当前实现](current-implementation.md)。未连接业务的设计原型、虚构图稿分支及其检查结果已移除；本文只保留有效页面要求和跨页规则。

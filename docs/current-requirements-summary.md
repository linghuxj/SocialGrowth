# SocialGrowth 当前需求总览

更新：2026-09-26。根据本轮已确认的 R-001 至 R-070 整理；完整来源与待明确细节见 [需求对齐记录](requirements-alignment.md)。旧归档仅作参考。本总览不表示实现或验收已完成。

## 业务与使用者

- 首期服务媒体自动分发，以产品展示、短剧娱乐作为真实验证场景，后续再扩展其他手机任务。
- 内部运营人员使用系统，同时支持公司自营与客户代运营。客户暂不直接使用系统。
- 业务按运营项目组织，同一客户可以有多个项目；使用公司持有的媒体账号。
- 账号同期只属于一个项目；手机同期也只属于一个项目，其 FB 和 YT 身份均服务该项目。同一手机在同一平台不轮换发布身份。

## 内容与发布范围

- FB 公共主页 Page：视频和图文；YT：Shorts 与常规视频，按现有成品和运营目标选择，不增加剪辑制作范围。登录账号与 FB Page 分别记录。
- 运营批量上传公司制作或客户提供的成品；首期不承担剪辑、配音或从零生成成品。
- 首期短剧为公司或客户原创、委托制作，可提供制作来源证明；这不代表平台变现资格已获认可。
- 首次输入须尚未发布，由提供方声明、系统检查已有记录与重复内容，疑点转人工。
- 短剧按内容配置顺序：连续剧集的前一集确认发布成功后才能发布后续依赖剧集；独立宣传片可自由排期，仍受批准范围及有效窗口约束。
- 同一部连续短剧在同一平台固定一个账号连载，AI 初次匹配后保持一致，不逐集换号。FB 与 YT 分别维护进度，一个平台失败不自动阻塞另一平台；共享资源故障仍按实际影响范围处理。
- 同一内容每个平台只选一个账号发布；同一视频的语言版本共用名额，每个平台只选其中一个版本。
- 首期受众区域为东南亚和美洲。英语、西班牙语、葡萄牙语、印尼语、泰语仅为候选语言，具体国家、语言范围未定。

## 目标与 AI 运营闭环

阶段目标与约束 → 初始策略方向确认 → 内容分析与账号匹配 → 发布信息和执行计划 → 手机执行 → 发布核验及效果采集 → 周期复盘与自修正。

- AI 主导常规运营，运营人员确认阶段目标、约束与初始方向，并处理重大问题、方向变化和必要验证。
- 账号未达标时优先推进广告分成资格，同时保留引流；达标后按项目设置广告收益与引流的阶段优先级，两者均保留。
- 同一项目内按账号的实际资格阶段分别安排策略，由项目统一协调资源。
- 已批准范围内的内容选择、账号匹配、时段和文案可自主优化；改变主目标、方向或突破范围须重新确认。
- 按项目配置周期集中复盘，重大异常及时处理。

## 引流与数据

- 业务方提供商品页、店铺、短剧观看页或 App 等现成入口；系统不建设承接页面。
- 系统生成关联项目、账号、内容的可追踪链接，必要时使用短链。链接的配置关联不等于点击来源已被证明。允许按账号统计；只有证据充分时才归因到内容，否则保留内容来源未知，AI 不据此判断单条视频的引流效果。具体入口能力与实际归因粒度仍需核验。
- 首期引流指标为排除已识别预览请求和重复记录后的链接点击；不将点击等同真人访问或实际到达。后续有可靠到达数据时可变更指标，保留前后口径。
- 效果数据可来自官方接口、授权第三方或手机后台，具体指标、权限、费用和刷新频率逐项核验。
- 主目标数据缺失时继续原批准范围内计划，暂停依赖缺失数据的优化并尝试补齐，不将缺失当作零。

## 执行与人工协作

- 账号预先创建，AI 协助手机登录与初始化，必要验证交人工。
- 凭据受控保存、按需填入，密码不进入 AI 对话、截图或普通日志。
- 需要人工处理的问题局部暂停，其余继续；人工提交已处理后由 AI 复核恢复。
- 管理台支持远程查看、操作手机；接管期间该手机的 AI 操作暂停，交还后复核恢复。无法远程处理时可由现场协助。
- 发布成功需在目标平台核对正确身份与内容并保存证据；结果未知先核实，避免重复发布。
- 允许可配置并发与排队。尚未开始发布的任务可在批准有效窗口内重新排期，超出窗口交运营处理。

## 设备与网络约束

- 首期管理 20–50 台分散部署的手机；各地点不能依赖额外网关或常在线电脑。
- 统一 Android 原厂系统，不 Root 或改造系统；允许安装代理并完成必要授权。
- 仅兼容选定型号与版本，先拟定候选范围、再筛选机器实测。重启或权限失效时允许必要现场协助。
- 管理连接与部分国内手机的业务上网按用途分开，不要求两款独立 VPN App。
- Tailscale 与 Exit Node 仅为候选；境外服务器计划采购、尚无可用节点。手机主动登记与任务回传为技术建议，mDNS 不能假定跨 VPN 可用。

## 交付原则

首期开始试运行以完整闭环验证通过为准，当前不设固定日期。系统通过真实内容与手机验证执行、反馈和自修正；广告分成资格、实际收益和引流目标另行持续评价，不作为系统验收的统一前置条件。详见 [首期验收清单](acceptance-plan.md)。

完整业务步骤与异常分支见 [业务流程复核稿](business-workflow.md)，由已确认需求整理，尚未实机验证。

## 仍需确定或验证

- 验收样本、观察窗口、性能与可靠性阈值、实际并发与计划容量。
- FB/YT 分成计划及资格、内容原创性要求、具体发布入口与链接能力、跨平台复用的实际影响。
- 指标来源与口径、账号阶段变化、引流最低要求及复盘周期。
- 执行代理权限、远程接管、后台运行、重启恢复、支持机型与版本。
- 中心与出口部署、实际国内网络可达性、素材与截图带宽及故障恢复。

# FL-02：导流入口与维护

状态：规格已整理，应用实现及验收未完成。属于用户确认的首批开发范围；发布 Issue 不触发代码实现或真实运营动作。

## 问题陈述

运营需要为实际客户内容维护可用受众路径，并区分访问、过滤点击和跳转响应；共享入口、目的地变化和退出不能被简化成所有旧链接自动换域名或转给新客户。

## 解决方案与完成标准

- [ ] 入口保存客户/项目、账号、内容或频道范围、实际目的地/版本及维护权限。
- [ ] 入口变更列出受影响历史内容，按原客户授权处理；共享入口不伪分摊到单条视频。
- [ ] 原始访问、过滤点击、HTTP 跳转响应分别记录；未观察到的到达/转化不填零或成功。
- [ ] 预览与实际目的地一致；服务故障、目的地失效、平台限制分别呈现。
- [ ] 退出后按约定继续或停用旧入口，不自动改指无关客户；界面与持久化一致。

## 用户故事

1. 作为运营人员，我希望为客户内容配置真实入口，以便受众能找到对应目的地。
2. 作为分析人员，我希望看到入口的真实归因层级，以便不把频道点击误算成某条内容的效果。
3. 作为项目负责人，我希望变更和退出时保留旧版本及维护责任，以便不误导历史受众或转用客户资产。

## 实施决定

复用 shortlink-service 职责和现有过滤逻辑前先核查适用性，按当前入口规则持久化版本及事件。FB/YT 各按实际入口说明粒度；URL 格式检查不等于真实可达或获准。具体路由随实施确定，但业务输入/输出须与执行契约中的服务边界一致。

## 测试决定

覆盖 C-06/08/12、T-11 的入口部分；通过服务公开入口验证正确目标、无权限拒绝、变更历史、继续/停用及访问/过滤/响应计数。受控 HTTP 响应不算真实平台入口验收，真实受众路径与预览另以实际证据验证。

以上为待执行的应用验证计划；此前通过的文档/样例结构检查不能替代。本任务完成记录应附实现提交、实际测试命令与结果、受控及真实接入范围。

## 不在本次范围

不承诺换域名无损恢复、零跳失、单条归因普遍可得或订单转化已接入；不自动更改真实客户域名/目的地。

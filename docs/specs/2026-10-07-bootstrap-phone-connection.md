# B1 首次手机连接

依据 R-166。当前为 dev 候选实现，尚无无旧信任的实机首次配对或管理切换验收。

## 操作链

1. 新手机安装 SocialGrowth，受邀注册并关联本机。连接稳定 Wi-Fi。
2. 点击“准备配对通知”，允许通知；App 先建立经过安装身份校验的 WSS 通道，再打开系统设置。
3. 用户启用开发者选项、无线调试和配对弹窗。弹窗保持打开，通过 SocialGrowth 通知内回复 6 位码；不切回 App。
4. 服务器通过通道执行真实 TLS 配对、连接和硬件序列号读取。Web“执行与人工协助 → 手机接入与准备”只展示当前真实状态。
5. 运营申请人工接管，点击“开始手机准备（不执行业务）”。Artemis 复用受控检查、人工协助和原回执；不发起媒体账号、参与或发布任务。
6. 已结束准备任务后，填写手机实际管理网络 IP，点击“核验并切换管理连接”。平台核验 Tailscale 在线节点和相同手机的真实 ADB 身份，成功才结束临时通道。此操作自动保存作用域绑定，不手写逐设备服务器 allowlist。

当前步骤 5 的安装包、SFA 配置与订阅仍须来自已有受保护配置或人工协助。没有自动创建云服务、自动签发逐手机密钥、绕过系统授权或自动交付所有机型配置的实现。步骤 6 需要运营从实际配置结果获取 IP；不是无人值守切换。

## 实现边界

- `bootstrap` 为临时通道，`managed_verified` 为经首次手机核验后的管理连接；二者均不写正式网络准入或业务许可。
- WSS 路径 `/api/installation/bootstrap`，仅安装身份 Authorization header；无 query token、浏览器 Origin、任意主机/端口代理。
- 手机只连接本机 NSD 刚发现的两类无线调试端口。中心监听随机回环端口，最多 100 会话、每会话 8 TCP 流、每方向逐 32 KiB ACK，队列和有效期有界；5 秒复核安装归属，失效关闭。首期单后端实例，不支持多副本无粘性路由。
- 连接服务可见、非 sticky；暂停、身份变化、端口撤回、断网和过期时失效。网络失败仅重建连接，不重发未知配对或业务任务。
- 首次接入会话重建会失去原执行 TCP，当前 Artemis 任务仍须按原任务核实；不能把自动重连称为任务自动续跑。
- 管理切换期间保留原通道，核验未通过不关闭；已成功切换但后续断网仍需回到 App 检查。首次接入、已有配对恢复、休眠、换 Wi-Fi 和重启分别验收。

## 部署与验收

需迁移 `0048_bootstrap_device_connection.sql`，后端及执行器启用 `SG_PRODUCT_BOOTSTRAP_ENABLED=true`。execution overlay 共享后端网络命名空间，ADB 与临时端口仅监听回环；执行器 4318 由后端通过 `127.0.0.1` 访问，不发布 ADB/转发公网端口。两者共享原 UID 1000 ADB 状态。不得在后端容器替换时遗漏重新创建执行器。

必须补验：生产签名 APK 安装；同机保持配对弹窗的无旧信任首次配对；真实 Web 发起 Artemis → 人工系统授权 → 真实回执；管理路径切换失败保留通道、成功后仍能控制同一设备；暂停、断线及作用域撤销。协议测试、构建和空设备 Web 页面验证不代替这些结果。通过前不晋级 main 或更新正式下载。

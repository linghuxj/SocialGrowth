# 首期验收清单

更新：2026-09-26。状态：依据已确认需求整理的初步清单，尚未执行；样本数、观察窗口、并发和可靠性阈值待细化。

本轮业务依据见 [需求对齐记录](requirements-alignment.md)，总览见 [当前需求总览](current-requirements-summary.md)。旧验收记录不能直接证明本轮需求通过。

## 验收原则

- 系统验收与商业结果分别评价。系统以真实内容、手机、平台结果及可追溯反馈证明闭环；商业侧持续记录分成资格、广告收益和引流结果。
- 验证通过、失败、阻断、未验证分别记录。方案调研、页面可访问或脚本未报错均不等于业务验收通过。
- Web 操作遵循当前工程规范，使用 Playwright 从真实入口验证。设备操作与平台结果也需有真实证据，不能以模拟成功替代。
- 本清单不宣称已启动服务、连接设备或完成发布；实际执行遵守仓库既有操作与发布授权边界。

## 系统验收场景

| 场景 | 需要证明的行为 | 应保留的证据 |
| --- | --- | --- |
| 项目与资源绑定 | 自营和客户项目可分别管理；账号、手机同期项目专用；FB Page 与登录账号区分 | 项目与绑定记录、错误分配的拒绝结果 |
| 内容输入 | 支持批量上传成品、来源及未发布声明；短剧可关联原创或委托制作的来源证明，发现重复或疑点时转人工；同视频语言版本共用名额 | 上传记录、短剧制作来源证明、内容归组及疑点处理记录 |
| 策略与计划 | 项目目标和范围经确认；账号按资格阶段分别安排；生成发布信息与可执行任务 | 策略版本、依据、确认记录、任务来源 |
| 登录初始化 | 已有账号由 AI 协助登录，必要验证交人工；核验正确发布身份后就绪 | 脱敏过程记录、身份核验结果、人工协助单 |
| 真实发布 | 覆盖产品展示与短剧场景，以及 FB 视频/图文、YT Shorts/常规视频所需入口；遵守每平台单账号规则，同一部连续短剧在同一平台保持同一账号连载 | 任务与设备记录、平台内容核验及可追溯发布证据 |
| 调度 | 支持配置并发、队列与窗口内重新排期；连续剧集等待前一集发布核验成功，独立宣传片可自由排期；超窗转人工，结果未知先核实 | 排期变化、并发执行记录、前置失败或待核实时后续等待及核验成功后解除依赖的记录、超窗处置 |
| 跨平台连载 | FB 与 YT 各自推进顺序；FB 第 3 集失败且 YT 第 3 集成功时，仅 FB 后续依赖等待，YT 第 4 集在其他条件满足时可继续；共享设备故障按实际影响暂停 | 分平台依赖与进度记录、失败局部隔离及共享故障处置证据 |
| 引流统计 | 验证实际发布位置可点击；追踪链接关联项目、账号和内容，允许账号级统计，内容来源不明时不强行归因，AI 不由此判断单条视频贡献；按既定过滤口径记录点击 | 观众侧点击与跳转证据、链接映射、访问和过滤记录、实际归因粒度 |
| 效果采集 | 至少以实际可用渠道取得评价所需数据；来源、时间、口径和缺失可追踪 | 采集记录、权限或可用性核验、与来源对照结果 |
| 反馈与自修正 | 按周期读取真实反馈、形成有依据的复盘，并落实范围内优化；越界变更转人工 | 复盘依据、策略及计划前后版本、后续执行记录 |
| 数据缺失 | 保留效果未知，继续原批准范围内计划，暂停依赖缺失数据的优化并补齐 | 缺失状态、受影响决策记录、补齐与重新评价结果 |
| 人工接管 | 管理台可远程操作手机，AI 同期不争用；交还后复核恢复，其他设备可继续 | 接管与交接记录、互斥结果、恢复核验 |
| 设备与网络恢复 | 无 Root、无现场网关条件下验证手机接入、掉线及权限恢复；必要时现场协助 | 实机环境、连接日志、故障过程、现场介入与恢复结果 |

这些场景需要组合成真实业务链路。一次成功发布只证明一个环节；尚未完成反馈、修正或人工协作验证时，不把整个闭环记为通过。

## 商业结果台账

| 结果 | 评价内容 | 当前边界 |
| --- | --- | --- |
| 广告分成资格 | 按账号、平台及具体计划记录资格状态与证据 | 官方规则、地区及账号适用性待核验 |
| 广告收益 | 记录来源口径、统计周期及实际收益 | 未确认金额目标，不从取得资格推定已有收入 |
| 曝光与账号成长 | 记录可用的曝光、观看、粉丝或订阅表现 | 与分成条件及阶段目标分别关联，阈值待核验 |
| 产品及短剧引流 | 首期按过滤后的链接点击评价，目标值待定 | 不等同到达或成交；后续到达指标需另定口径与生效范围 |

系统可以证明复盘与调整流程已运行，而效果证据仍不足；此时分别记录系统结果和商业结果，不把一次指标上涨直接解释为策略带来的改善。

## 验证准备与待定参数

- 真实成品、账号、Page/频道及分配关系，以及可执行的发布范围。
- 候选手机型号与系统版本；先筛选实机验证，再确定正式支持范围。
- 中心与境外出口资源、实际部署网络。境外节点目前计划采购，Tailscale 方案未实测。
- 支持 20–50 台管理的验证安排与资源，不以少量样机成功推定全量稳定。
- 试验样本、复盘周期、观察窗口、并发数、完成率、延迟与恢复时限；尚无确认值，不自行填写为已通过门槛。
- 跨平台复用影响、各平台链接可用性及分成规则的核查结果，分别见研究记录并待补充。

[平台与 Android 核查](research/platform-and-android-feasibility.md)发现需覆盖的限制：Shorts 简介/评论外链不可点击、FB 变现邀请状态、投屏会话重新授权与锁屏恢复。YT 发布形式已确认两者均支持；具体引流方案及代理部署方式仍待选择，未记为已通过。

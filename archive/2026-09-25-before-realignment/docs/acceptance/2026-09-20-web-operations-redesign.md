# Web 运营工作台首轮整改验收

日期：2026-09-20。环境：Chrome，本地 `http://127.0.0.1:3000/`。

## 结论

首轮 Web 结构整改通过本地受控验收。旧演示运行入口和静态演示数据库已移除，运营页面统一读取首批闭环状态。该结论不包含真实平台账号、真机执行器、生产数据库或真实指标源验收。

## Chrome 验收结果

- 桌面视口确认运营总览、项目与授权、内容库存、入口与策略、批准与排期、观察与复盘、审计日志均可到达。
- 当前项目选择贯穿各任务页面；已有 `Chrome验收项目` 与演练项目可切换。
- 项目、授权、内容、入口、策略、批准、排期和观察控件均有可访问名称。
- 批准缺少数量、有效期、停止或观察条件时，页面显示 `APPROVAL_SCOPE_INCOMPLETE`，未生成新批准。
- 执行页面明确显示外部执行器未配置，且不存在 Ping、自愈、2FA、批量下发或伪发布回执按钮。
- 观察页面将已观察值、真实零、缺失、延迟和无权限分开；已观察值为空不会被转换为零。
- 复盘页面要求运营人员显式确认必需工作是否完成及不同来源是否可比。
- 390×844 移动视口中，顶栏、菜单、表单、错误提示与批准详情无横向溢出；移动导航可展开并进入观察与复盘。
